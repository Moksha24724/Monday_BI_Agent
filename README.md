# 🤖 Monday Business Intelligence Agent

A Business Intelligence Dashboard built using **Python**, **Streamlit**, and the **Monday.com API**.

## 🚀 Features

- 📊 Interactive Dashboard
- 📈 Business Analytics
- 🤖 AI Business Assistant
- 🔍 Search and Filter Records
- 📥 Export Data to CSV
- 📊 Interactive Charts using Plotly
- 🔄 Real-time data from Monday.com

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- Monday.com API

## 📁 Project Structure

```
Monday_BI_Agent/
│── app.py
│── chatbot.py
│── monday_api.py
│── data_cleaner.py
│── utils.py
│── requirements.txt
│── README.md
```

## ▶️ How to Run

```bash
pip install -r requirements.txt
streamlit run app.py
```
